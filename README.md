# Modern Inventory System

A sleek and modern inventory system for FiveM servers.

## Features

- Modern and sleek UI layout
- Item management with use and drop functionality
- Weight limits and slot configuration

## Requirements

- FiveM server
- ESX Framework
- ox_lib
- ox_inventory
- ox_target

## Installation

1. Download the script from the [GitHub repository](https://github.com/EnderDevelopment/modern-inventory-system).
2. Extract the files into your FiveM server's resources folder.
3. Add `start moderninventorysystem` to your server.cfg file.

## Usage

- Open the inventory by typing `/inventory` in the chat or pressing the E key.
- Use items by clicking on them and selecting the 'Use' option.
- Drop items by clicking on them and selecting the 'Drop' option.

## Configuration

The script can be configured in the `config.lua` file. You can adjust the weight limit, number of slots, and UI settings.
